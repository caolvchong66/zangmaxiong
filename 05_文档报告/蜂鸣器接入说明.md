# 藏马熊识别 → 蜂鸣器报警 接入说明

## 1. 硬件接线（已确认）

| 蜂鸣器模块（普中-传感器模块v2） | 接到 | 说明 |
|---|---|---|
| VCC | 3.3V | 模块 3.3V 供电即可 |
| GND | GND | 共地 |
| BP（BEEP） | **PL_TX** | 板上 J21 跳线排的 “PL_TX” 孔 —— 该网络是 `PL_UART_TX`，直接连到 FPGA 的 **E18** 引脚 |

依据：底板原理图 `09_UART_PL_DEVICE`（J21 / PL_UART_TX）＋ `Z20 ZYNQ开发板IO引脚分配表`（PL USB UART：uart_txd = E18）＋ 装配图 J21 丝印 `PL_TX`。

> J21 上如果还插着跳线帽（把 PL 串口接到 CH340），蜂鸣器的 2 kHz 方波会顺带串进 CH340 的 RXD，只会让虚拟串口收到乱码，不影响蜂鸣器和板子。

## 2. 为什么这样能响

普中蜂鸣器模块是**无源蜂鸣器**（官方 Arduino 例程就是每 250 µs 翻转一次 IO）。所以：

* 输出 **2 kHz 方波** → 发声；
* 输出**直流电平** → 不发声（因此不存在“高电平有效/低电平有效”接反的问题）。

## 3. PL 端改动（Vivado）

* 块设计中 `axi_gpio_0` 由单通道改为**双通道**：通道 1 仍是 3 bit 的 LCD ID 输入（不动），通道 2 为 1 bit 输出；
* 新增顶层端口 `buzzer`，由 `axi_gpio_0/gpio2_io_o[0]` 驱动；
* 约束文件 `pin.xdc` 追加：

```tcl
set_property -dict {PACKAGE_PIN E18 IOSTANDARD LVCMOS33} [get_ports buzzer]
```

* 重新综合/实现，生成新的 `system_wrapper.bit`。

> PS 的 EMIO GPIO 只有 4 bit，已全部给双目 SCCB 使用，所以走 AXI GPIO 第二通道，没有动 PS 配置，BSP/地址映射不变（AXI GPIO 仍在 0x41200000）。

## 4. PS 端改动（`main.c`）

* 新增 `buzzer_init()` / `buzzer_tone_ms()` / `buzzer_alarm()`，用 AXI GPIO **通道 2** 输出 2 kHz 方波（`usleep(250)` 翻转）；
* 上电自检：初始化后响 120 ms，串口日志（JTAG 读 DDR 日志）里会打印
  `BUZZ: PL E18 (J21 PL_TX) ready, 2 kHz passive tone`；
* 报警逻辑（持续报警版）：
  * 蜂鸣器不再由主循环阻塞发声，而是由 **4 kHz 的 SCU 定时器中断**驱动：
    每个 tick 翻转一次 IO → 2 kHz 方波，主循环完全不阻塞；
  * 只要某一帧检出藏马熊，就把 `g_alarm_until = g_ticks + 6 s`，立即开始响，
    并一直响到熊离开画面 6 s 后自动停；
  * 推理期间（约 3 s 一帧）不会断音，因为发声是中断在做；
  * 主循环末尾原来的 `sleep(1)` 已改成 20 ms，响应更快，还给 LCD 留带宽。

## 5. 生成与烧录

```text
1) Vivado：build_hw.tcl  → system_wrapper.bit
2) 应用  ：build_app.ps1 → bear_app.elf（-O3 -mfpu=neon -mfloat-abi=hard）
3) 打包  ：bootgen -image boot.bif -arch zynq -o BOOT.bin -w on
4) SD 卡 ：把 BOOT.bin 放卡根目录，启动模式拨到 SD
   或 JTAG：program.tcl（xsdb：rst -system → fpga -file bit → dow elf → con）
```

## 6. 自检与排错

| 现象 | 处理 |
|---|---|
| 上电没有 120 ms 自检声 | 先确认 BP 插在 J21 的 `PL_TX` 孔（不是 PS_TX）；再确认模块 VCC=3.3V、GND 共地 |
| 自检有声，检测到熊不响 | 看日志有没有 `BUZZ: bear detected, alarm!`；没有则是没检出目标（置信度/光照问题） |
| 一直响不停 | 说明 BP 接在了直流有效的有源蜂鸣器上 / 接错孔，改成只输出方波或换孔 |
| 声音很小 | 模块若是 5V 有源蜂鸣器，3.3V 会偏轻，可把 VCC 接 5V（BP 仍是 3.3V 逻辑） |
