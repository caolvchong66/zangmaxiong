烧录与启动说明
==============

本目录镜像版本：2026-11-03（含蜂鸣器报警，FPGA E18 / J21 PL_TX）

【方式一：SD 卡启动（推荐，无需电脑）】
 1. SD 卡格式化为 FAT32（≤32GB）；
 2. 将本目录 BOOT.bin 复制到 SD 卡根目录（不要改名）；
 3. SD 卡插入开发板卡槽，启动模式拨码选择 SD 启动；
 4. 上电，3~5 秒后开始运行；启动约 1 秒时会有一声 120 ms 的蜂鸣器自检音。

【方式二：JTAG 在线运行（调试用）】
 在 Vitis 中：Xilinx → Program FPGA（选择 bear.bit），
 再 Run/Debug bear_app.elf（需先运行 ps7_init）。
 或用 xsdb 脚本：
   connect
   targets -set -filter {name =~ "APU*"}
   rst -system
   fpga -file bear.bit
   targets -set -nocase -filter {name =~ "ARM*#0"}
   source ps7_init.tcl
   ps7_init
   ps7_post_config
   dow bear_app.elf
   con

【方式三：QSPI Flash 固化】
 用 Vitis 的 Program Flash 功能，将 BOOT.bin 写入 QSPI，
 启动模式改为 QSPI 启动。

【文件说明】
 BOOT.bin      = FSBL + bear.bit + bear_app.elf（完整启动镜像，7.3 MB）
 bear.bit      = PL 比特流（单路 OV5640（左目）采集 + 3×VDMA + VTC + clk_wiz + rgb2lcd
                 + AXI GPIO 通道2 → buzzer 输出 E18）
 bear_app.elf  = PS 应用程序（含 INT8 模型权重 + 蜂鸣器报警）
 fsbl.elf      = 第一阶段引导程序（单独调试时用）

【蜂鸣器（本版新增）】
 接线：模块 VCC→3.3V，GND→GND，BP(BEEP)→J21 跳线排的 PL_TX 孔（FPGA E18）。
 行为：上电 120 ms 自检音；检出藏马熊立即持续报警；
       熊离开画面约 6 s 后自动停止。
 注意：这是无源蜂鸣器，靠 2 kHz 方波发声；若上电完全没声，
       先确认 BP 插的是 PL_TX（不是 PS_TX）、模块供电是否 3.3V。
       详细说明见 05_文档报告/蜂鸣器接入说明.md。
