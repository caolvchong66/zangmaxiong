上位机工具说明
==============

 bear_monitor.py —— 通过 JTAG 实时读取板卡 DDR 中的标注帧并显示

 依赖：
   pip install numpy opencv-python
   已安装 Vitis 2020.2（使用其中的 xsdb.bat）

 使用：
   1. 开发板已上电、JTAG 已连接、程序已运行；
   2. 启动 hw_server（Vitis 自带，默认端口 3121）；
   3. 运行：python bear_monitor.py
   4. 弹窗显示 320×320 标注帧，控制台打印最近日志；按 q 或 ESC 退出。

 说明：
   JTAG 读取带宽有限，约 1~3 秒/帧，仅用于无 LCD 时的演示与调试。
   板端标注帧固定存放于 DDR 0x0D000000（480×272 或 320×320），
   日志位于 0x0F000000（magic 'JLOG' + 长度 + 文本）。
